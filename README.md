# TechBuddy 🚀

TechBuddy is a platform designed for developers to connect with like-minded peers. Whether you're looking for a **coding partner**, a **hackathon teammate**, or just someone to **geek out with**, TechBuddy helps you find the right connections effortlessly.

## 🎯 Features

- 🔥 **Swipe to Connect** – Find developers based on shared interests.
- 💬 **Real-time Chat** – Message your matches instantly.
- 🌍 **Global & Local Networking** – Connect with developers near you or worldwide.
- 🔒 **Secure Authentication** – Ensures privacy and a safe environment.

## 🛠 Tech Stack

### Backend:
- **Node.js** with **Express.js** – Efficient and scalable server-side framework.
- **MongoDB** – NoSQL database for seamless data storage.
- **JWT Authentication** – Secure user authentication and session management.

### Frontend: *(Coming soon!)*  
- **React.js / Next.js** *(planned)* for a smooth and interactive user experience.
